## 🚀 How to Publish to GitHub Pages

1. Open your terminal in this directory:
   ```bash
   cd c:\Uma\Birthday
   git init
   git add .
   git commit -m "Happy 24th Birthday Uma celebration page"
   ```
2. Create a new repository on GitHub (e.g. `uma-birthday`).
3. Link and push:
   ```bash
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
4. On GitHub, navigate to **Settings** > **Pages** > Select `main` branch (root) > **Save**.
5. Your website link will be live in ~1-2 minutes!
